# GPB Category Fields Correction

Budget Allocation and Monthly Utilization now render category-specific inputs based on the GPB Encoding Template's BUDGET PLAN columns.

- PS: position, staff, hours, optional patients/participants, salary grade, hourly rate, total rate, total PS.
- Materials: item, quantity, unit price, total material cost.
- Venue/Food: item, number of packs, price per pack, total venue/food cost.
- Patient Expense: expense type, item, number of patients, quantity per patient, unit price, total patient expense.
- Honoraria: item/resource person, rate per hour, number of hours, total honoraria.

Non-PS categories no longer display or persist PS-only fields (position, staff count, salary grade, basic/monthly salary, PS hourly rate). Utilization follows the same category-specific fields.
